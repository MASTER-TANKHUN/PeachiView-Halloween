# เพลย์เทสบนเครื่องจริง (สัปดาห์ 5)

สิ่งที่ทดสอบอัตโนมัติไม่ได้ (เสียง, ไมค์, ความลื่น, ความสนุก) ต้องลองเล่นเอง ลองบนคอมแรงๆ 1 เครื่องและคอมธรรมดา/โน้ตบุ๊ก 1 เครื่อง

ตั้งค่า → **แสดง FPS** เพื่อดูตัวเลขมุมล่าง (ถ้าต่ำกว่า 40 เกมจะลดความละเอียดเองและโชว์ % ต่อท้าย)

## 1. ความลื่น (FPS)
- [ ] หน้าแรก: FPS ___
- [ ] คืน 1 เดินทั่วบ้าน: FPS ___
- [ ] คืน 2 หน้ากระจกห้องน้ำ + ตอนไฟดับ: FPS ___
- [ ] คืน 3 หน้ากระจกโถง + ผีปอบ + ตัวปลอม (`?night=3&hour=2.5&autostart=1`): FPS ___
- [ ] บอส (`?night=3&boss=1&autostart=1`): FPS ___
- [ ] ถ้าไม่ถึง 40: ลองคุณภาพ "กลาง" / "ต่ำ" แล้วจดว่าอันไหนพอเล่นได้

## 2. เสียง
- [ ] เสียงดังเบาพอดีไหม (ตุ้งแช่ของพีชชี่/ผีปอบ/ตัวปลอม ดังเกินไปไหม)
- [ ] โหมดสตรีมเมอร์: เสียงตุ้งแช่เบาลงจริงไหม
- [ ] คาราโอเกะ: จังหวะตรงกับตัวโน้ตไหม
- [ ] ไมค์: กรี๊ดแล้วผีสะดุ้ง (ระยะ 7 ม.) · ตอนซ่อนพูดแล้วโดนเจอ
- [ ] บลูเปอร์ท้ายเครดิต: เสียงสเลต, เรอ, ค้อน, หัวเราะ

## 3. บาลานซ์ (จดเวลาที่ผ่าน/ตายกี่รอบ)
- [ ] คืน 1 ปกติ: ตาย ___ ครั้ง · พีชชี่ไล่ทันเร็วไปไหม
- [ ] คืน 2: จับผิดบ้าน 5 จุดยากไปไหม · กระสือตามแสงน่ารำคาญไปไหม
- [ ] คืน 3: ขนมหมดเร็วไปไหม · ผีปอบหิวเร็วไปไหม · หาโชคเกอร์ 3 ชิ้นทันไหม
- [ ] บอส เฟส 1 (แบน 12 ใน 30 วิ) · เฟส 2 (ชิ้นละ 40 วิ) · เฟส 3 (ช่องค้อนชมพู 1.8 วิ กด Space ทันไหม)
- [ ] ลูกพีชน้อย: คุกห้องน้ำ 30 วิ พอไหม · ตีสาม: ยากเกินไปไหม

## 4. ความสนุก
- [ ] ช่วงไหนน่าเบื่อ/รอนาน
- [ ] มินิเกม (POPCAT, เต้น, คาราโอเกะ, กระดานวิญญาณ) อันไหนสนุก/ไม่สนุก
- [ ] ร้านลูกพีช: ของราคาเหมาะไหม เงินพอซื้อไหม

## ลิงก์ช่วยทดสอบ
| ลิงก์ | ใช้ทำอะไร |
|---|---|
| `?night=2&autostart=1` | เข้าคืน 2 ทันที |
| `?night=3&hour=4&autostart=1` | คืน 3 ตีสี่ (ห้องแห่งการรอ) |
| `?night=3&boss=1&autostart=1` | บอส |
| `?ending=1&autostart=1` | ฉากจบ + เครดิต + บลูเปอร์ |
| `?date=2026-10-31` | หน้าแรกวันฮาโลวีน |
| `&god=1` | ไม่ตาย · `&speed=5` นาฬิกาเร็ว 5 เท่า |
